# Yunwu (Med AI Assistant)

## 安装与运行指南

### 1. 克隆与进入目录
克隆项目到本地并进入文件夹。

### 2. 打开 PowerShell
在文件夹内右键打开 **PowerShell**（如果没有该选项，请打开 PowerShell 后使用 `cd` 命令进入该文件夹）。

### 3. 安装依赖
在 PowerShell 中输入并运行：
```powershell
npm install
```

### 4. 构建应用
依赖安装完成后，输入并运行：
```powershell
npm run build
```

### 5. 安装与配置
*   构建完成后，会生成一个 `.exe` 安装文件，双击进行自动安装。
*   打开应用后，会跳转到设置窗口（若未弹出，点击左下角的**设置**图标即可配置）。
*   填写以下配置并点击**保存**：
    *   **Base URL**: 中转站
